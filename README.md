# 江城投递

面向武汉实习求职的投递工作台。把公司、岗位、来源和下一步动作放进看板，用来管理投递，也可以当作前端作品演示。

## 能做什么

- **投递看板**：想投 → 已投 → 笔试 → 面试 → Offer / 未过，卡片可拖拽改阶段
- **武汉名录**：一份本地公司清单，可一键加入「想投」
- **面试怎么讲**：简历三条和一分钟 STAR 介绍，方便开口
- **本地存储**：数据在浏览器 `localStorage`，支持 JSON 导出 / 导入，没有账号系统

## 本地运行

需要 Node.js 20+。

```bash
npm install
npm run dev
```

浏览器打开终端里提示的地址（默认 `http://127.0.0.1:43145`）。

```bash
npm run build
npm start
```

## 简历上可以怎么写

独立完成实习投递工作台：Next.js、TypeScript、招聘漏斗看板、本地持久化、武汉公司名录。面试时现场演示增删改查、拖拽改状态和数据备份。

更完整的口吻见应用内「面试怎么讲」页。

## 技术栈

Next.js（App Router）、TypeScript、Tailwind CSS、shadcn/ui。
